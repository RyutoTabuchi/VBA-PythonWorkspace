# UserForm CSV ツール

UserFormのコントロール情報をCSVへ出力し、編集したCSVを既存ブックへ反映するVS Codeタスク用スクリプトです。

## ファイル

このフォルダーには、CSV出力・反映用PowerShellスクリプト、`UserFormCsvExporter.xlam`、アドインから読み出した `Module1.bas` を配置します。アドインはユーザーが追加したファイルです。`.gitignore` により `.xlam` はGit管理対象外です。

`Module1.bas` は、許可を得てアドインから読み出したコード本文のスナップショットです。CodeModuleから取得したため、モジュール属性行は含まず、ブックへ再インポートするための完全なVBEエクスポートではありません。内容には `Module1.ExportUserFormCsvFilesForPath` があり、CSV列も反映スクリプトの期待値と一致することを静的確認しました。`.bas` を編集しても `.xlam` 内のコードは変わりません。両者を変更する場合は、対象を明示して別途作業してください。

## CSV出力

VS Codeの「ターミナル」→「タスクの実行」から `Excel: UserForm情報をCSV出力（アドイン）` を選び、対象の `.xlsm` または `.xlsb` を指定します。Excelを別プロセスで起動し、対象ブックを読み取り専用で開きます。CSVは対象ブックと同じフォルダーへ出力されます。VBAプロジェクトへのアクセスには、ExcelのTrust Center設定が必要です。

このタスクはExcelを起動してブックを読み取り専用で開き、アドイン内のマクロを実行してCSVを書き出します。AIに実行を依頼する場合は、共通instructionsの手順に従い、対象ブックのフルパスと操作内容について事前に許可を確認してください。マクロ実行もExcel操作に該当します。

## CSV反映

VS Codeのタスク `Excel: 編集したUserForm CSVをExcelへ反映` を選び、対象ブックとCSVを指定します。CSVに必要な列は `FormName`、`ParentControl`、`ControlName`、`ControlType`、`Caption`、`Top`、`Left`、`Width`、`Height`、`TabIndex` です。フォーム名、親コントロール名、コントロール名など識別列は変更しないでください。

反映対象は既存コントロールのCaption・位置・サイズ・TabIndexに限られます。追加・削除・種類変更やフォーム全体の設定は扱いません。反映前に概要を表示して確認を求め、同じフォルダーへタイムスタンプ付きのブックバックアップを作成してから更新・保存します。対象ブックが開いている場合は、未保存変更を保存して閉じてから実行してください。

このタスクはExcelを起動し、ブックを変更・保存します。AIに実行を依頼する場合、CSVの確認ダイアログだけでは事前許可の代わりになりません。共通instructionsに従い、対象ブックのフルパス、対象UserForm、変更内容と保存の有無について別途許可を確認してください。

## 注意

- どちらのスクリプトもExcelデスクトップ版とWindows PowerShellのSTA実行を必要とします。
- VBAプロジェクトが保護されている場合や、Trust Centerの「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」が無効な場合は利用できません。
- パスワード入力などExcelの対話操作を要求するブックは対象外です。
- このワークスペースでは、Excelを使った出力・反映の実動作確認は未実施です。
