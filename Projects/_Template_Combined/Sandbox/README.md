# Sandbox: VBA・Pythonの試作と検証

本番へ採用する前の試作コードと、必要に応じて用意する試作用Excelブックを置きます。
本番ブックからエクスポートしたVBAソースは `../VBsource/`、採用したPythonコードは `../Pysource/` で管理します。
このフォルダーのコードは、本番へ反映済みとは限りません。既存の自動テストがある場合は、そちらも引き続き利用してください。

## 試作・検証を追加するとき

用途が分かる名前でファイルを保存し、次の情報をこのREADMEに追記してください。実施していない確認は「未検証」と記載します。

- 目的と対象ファイル。
- 関連する本番ブック・モジュール・Pythonコード。
- 実行入口、手順、使用するPythonのバージョン。
- 必要なシート、データ、参照設定、外部パッケージ。
- 期待結果と、実際に確認した結果。
- セル変更、ファイル出力などの副作用と、本番への反映状況。

## Excelで検証するとき

- 本番ブックではなく、コピーした試作用ブックを使います。
- CopilotがExcelを起動する場合も、対象ブックを示して事前に許可を確認します。読み取りの許可は、マクロ実行・コード反映・保存の許可を含みません。
- ソースを保存・編集しただけでは、ブック内のVBAコードは変わりません。
- UserFormの `.frm` と `.frx` は同じ場所に保管します。
- 本番採用時はブックと `VBsource/ブック名/` の両方を更新し、Python側への影響も確認します。
- 秘密情報や個人情報をコード・試験データへ含めないでください。
